9 destinations, 3 formats each. 1024 x 683 (3:2).

USE
  AVIF  primary        ~40-65 KB
  WebP  fallback       ~60-95 KB

next/image serves AVIF then WebP automatically - just reference the .jpg
or point at the AVIF directly.

SUITABLE FOR
  Destination cards up to ~512px wide on retina.

NOT SUITABLE FOR
  Full-bleed hero or banner use. Source tiles were ~500px and have been
  upscaled 2x; they will look soft above ~600px display width.

NOTE
  These are AI-generated. Names describe what each frame resembles, not a
  verified location. Three are deliberately unnamed because they match no
  specific park: "elephants-waterhole-safari-lodge",
  "asian-elephant-forest-trail", "indian-gaur-safari-jeep".
  Replace with licensed or client-owned photography before launch.

  ANIMAL ID is reliable; PARK ATTRIBUTION is not. A one-horned rhino only
  occurs in Kaziranga/Chitwan, so that name is safe. "Bandhavgarh" and
  "Yala" are plausible-but-unverifiable - drop the park name if the client
  is not actually running trips there.
